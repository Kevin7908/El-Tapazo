# Backend — Django

API REST del sistema de inventario **El Tapaso**.

| | |
| --- | --- |
| Lenguaje | Python 3.13 |
| Framework | Django 5.2 LTS + Django REST Framework 3.16 |
| Base de datos | PostgreSQL 18 |
| Documentación API | `http://localhost:8000/api/docs/` |

## Arranque rápido

Desde la **raíz del repositorio** (no desde esta carpeta):

```bash
docker compose up backend
```

Guía completa: [`docs/guias/guia-instalacion.md`](../../docs/guias/guia-instalacion.md).
