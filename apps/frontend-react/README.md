# Frontend — React

Interfaz web del sistema de inventario **El Tapaso**.

| | |
| --- | --- |
| Runtime | Node.js 24 LTS |
| Librería | React 19 (JavaScript, sin TypeScript) |
| Build tool | Vite 8 |
| Datos | Axios + TanStack Query |
| Rutas | React Router 7 |

## Arranque rápido

Desde la **raíz del repositorio**:

```bash
docker compose up frontend
```

Queda en `http://localhost:5173`. Guía completa:
[`docs/guias/guia-instalacion.md`](../../docs/guias/guia-instalacion.md).
